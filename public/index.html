REST API Documentation

NC News Backend API

A Node.js + Express + PostgreSQL API for topics, articles, comments and users. This page documents the routes currently implemented in this project.

Base URL

https://jeff-nc-news.onrender.com

Local URL

http://localhost:9090

Content Type

application/json

Quick Start

List all articles sorted by newest first:

curl "http://localhost:9090/api/articles?sort_by=created_at&order=DESC"

Add a comment to an article:

curl -X POST "http://localhost:9090/api/articles/1/comments" \
  -H "Content-Type: application/json" \
  -d '{"username":"butter_bridge","body":"Great read!"}'

Endpoints

GET /api/topics

Retrieve all topics.

200 OK
{
  "topics": [
    {
      "slug": "coding",
      "description": "Code is love, code is life"
    }
  ]
}
GET /api/articles

Retrieve all articles. Supports filtering and sorting.

  • topic: filter by topic slug
  • sort_by: author, title, article_id, topic, created_at, votes, comment_count
  • order: ASC or DESC (uppercase)
200 OK
{
  "articles": [
    {
      "article_id": 1,
      "title": "Living in the shadow of a great man",
      "topic": "mitch",
      "author": "butter_bridge",
      "created_at": "2020-07-09T20:11:00.000Z",
      "votes": 100,
      "comment_count": 11
    }
  ]
}
GET /api/articles/:article_id

Retrieve one article by ID.

  • article_id (path): positive integer
200 OK
{
  "article": {
    "article_id": 1,
    "title": "Living in the shadow of a great man",
    "topic": "mitch",
    "author": "butter_bridge",
    "body": "I find this existence challenging",
    "created_at": "2020-07-09T20:11:00.000Z",
    "votes": 100,
    "article_img_url": "https://images.pexels.com/...",
    "comment_count": 11
  }
}
PATCH /api/articles/:article_id

Update article votes.

  • article_id (path): positive integer
  • inc_votes (body): number, required
Request Body
{
  "inc_votes": 1
}

200 OK
{
  "article": {
    "article_id": 1,
    "votes": 101
  }
}
GET /api/articles/:article_id/comments

Retrieve all comments for a specific article.

  • article_id (path): positive integer
200 OK
{
  "comments": [
    {
      "comment_id": 1,
      "article_id": 1,
      "author": "butter_bridge",
      "body": "Oh, I've got compassion running out of my nose, pal!",
      "votes": 16,
      "created_at": "2020-04-06T12:17:00.000Z"
    }
  ]
}
POST /api/articles/:article_id/comments

Add a comment to an article.

  • article_id (path): positive integer
  • username (body): string, required
  • body (body): string, required
Request Body
{
  "username": "butter_bridge",
  "body": "Great article!"
}

201 Created
{
  "comment": {
    "comment_id": 19,
    "article_id": 1,
    "author": "butter_bridge",
    "body": "Great article!",
    "votes": 0,
    "created_at": "2026-03-26T08:00:00.000Z"
  }
}
DELETE /api/comments/:comment_id

Delete a comment by ID.

  • comment_id (path): positive integer
204 No Content
PATCH /api/comments/:comment_id

Update comment votes.

  • comment_id (path): positive integer
  • inc_votes (body): number, required
Request Body
{
  "inc_votes": 1
}

200 OK
{
  "comment": {
    "comment_id": 1,
    "votes": 17
  }
}
GET /api/users

Retrieve all users.

200 OK
{
  "users": [
    {
      "username": "butter_bridge",
      "name": "jonny",
      "avatar_url": "https://www.healthytherapies.com/..."
    }
  ]
}
GET /api/users/:username

Retrieve one user by username.

  • username (path): string
200 OK
{
  "user": {
    "username": "butter_bridge",
    "name": "jonny",
    "avatar_url": "https://www.healthytherapies.com/..."
  }
}

Error Responses

Status When It Happens Message Example
400 Invalid id, invalid query/body fields, invalid JSON { "msg": "inc_votes is required" }
404 Resource not found or unknown route { "msg": "Article not found" }
500 Unexpected server-side failure { "msg": "Internal Server Error" }
